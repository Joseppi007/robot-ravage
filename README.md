# Robot Ravage
*Robot Ravage* is a school assignment wherein robots must communicate with one
another to navigate a grid and surround some target object. There are four
variants of the problem. In the first, all the robots know the positions of
all the other robots as well as where the target is. In the second, the robots
must find the target. In the third, the robots do not begin with the knowledge
of each other's locations. In the fourth, there are malicious robots; there are
at least one more than thrice as many non-malicious robots as there are
malicious robots. The malicious robots must not surround the target.

# Running the Code
Simply run `main.py`.
